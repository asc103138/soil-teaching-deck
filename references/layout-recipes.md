# Layout Recipes（投影片版型配方）

採用標準 16:9 寬螢幕畫布（寬度 13.333 英吋，高度 7.5 英吋）。
邊界安全留白至少 0.6 英吋，確保投影與各裝置螢幕不切邊。

---

## 一、投影片角色與推薦版型 (Page Roles & Layouts)

| 頁面角色 | 推薦版型結構 | 適用情境 |
|---|---|---|
| **封面** | 超大主標題 (72~84pt) + 副標 (28~34pt) + 講者/日期 + 右側或滿版留白主視覺 | 課程啟動、主題宣示 |
| **引起動機** | 單一巨大核心提問 (48~56pt) + 引起共鳴之痛點一句話 + 情境插圖 | 引起好奇、拋出認知衝突 |
| **迷思澄清** | 雙欄對比卡片（左欄：常見誤解 ❌ vs 右欄：正確理解 ✅） | 診斷學生盲點、打破刻板印象 |
| **概念解析** | 左側 45% 結構化要點 + 右側 50% 核心圖解或情境底圖 | 主題核心知識點拆解 |
| **流程步驟** | 3~4 步水平演進卡片（標記 1, 2, 3 步驟與引導箭頭） | 方法、實驗步驟、演算法 |
| **分類歸納** | 2x2 四象限矩陣 或 3 欄並列卡片 | 類型比較、多重維度歸納 |
| **真實案例** | 上半部或左半部生活實例 + 提煉出之核心意涵 | 落地應用、在地化連結 |
| **關鍵數據** | 單一超大關鍵數字 (80pt+) + 極簡詮釋句子 + 輔助視覺 | 數據震撼、建立迫切感 |
| **重點總結** | 三大外帶要點 (Takeaways) + 底部置中「帶走一句話」金句框 | 課堂收束、工作記憶固化 |
| **喚起行動** | 明確的課後行動指示（Action Steps）+ 鼓舞人心的結語 | 佈置任務、激發實踐 |
| **單元過渡** | 深色/沉浸式滿版情境底圖 + 單一過渡大字標題 (56pt) | 章節切換、心智轉換節奏點 |

## 二、版面網格預設值 (Grid Defaults for 16:9)

- **畫布尺寸**：寬 13.333 英吋（約 33.867 cm），高 7.5 英吋（約 19.05 cm）。
- **水平安全邊距**：左邊距 `0.65"~0.7"`，右邊距 `0.65"~0.7"`。
- **垂直安全邊距**：頂部邊距 `0.6"~0.8"`，底部留白 `0.6"~0.8"`。
- **雙欄切分 (50 : 50)**：
  - 左欄：起點 `0.65"`，寬度約 `5.7"`。
  - 欄間距：約 `0.6"`。
  - 右欄：起點 `6.95"`，寬度約 `5.7"`。
- **三欄卡片 (Three Cards)**：
  - 卡片 1：起點 `0.65"`，寬度約 `3.6"`。
  - 卡片 2：起點 `4.85"`，寬度約 `3.6"`。
  - 卡片 3：起點 `9.05"`，寬度約 `3.6"`。
  - 卡片間距：約 `0.6"`。
- **標準標題 Y 座標**：所有內頁標題 Y 座標建議固定在 `0.65"`，維持切換時的視覺穩定性。

## 三、AI 底圖 + 原生可編輯文字排版 (Image Plate + Editable Text)

在 Antigravity 生成教學簡報時，追求「精緻情境底圖」與「可編輯文字」的完美平衡：

1. **先規劃版型，再生底圖**：
   - 確定文字在左側還是右側，生成時就明確要求留白區域。
2. **黃金配置比例**：
   - 左側 42~45% 為平靜文字區域，右側為生動教學主視覺。
   - 或左側主視覺，右側 45% 為結構化知識卡片。
3. **避免常見排版雷區**：
   - 避免在已經豐富的圖片上加整張全黑覆蓋層（導致 AI 圖片失去色彩）。
   - 避免在大圖正中央放長篇條列清單。
   - 避免使用文字陰影重疊方塊來增加可讀性（應改用底圖預留留白或極簡半透明磨砂卡片）。

## 四、文字階層規範 (Text Hierarchy)

- **封面標題 (Cover Title)**：`72~84 pt`，加粗，主色或深色。
- **頁面主標題 (Slide Title)**：`44~56 pt`，加粗，不超過 10 個中文字。
- **副標題 / 區塊標題 (Subtitle / Section)**：`28~34 pt`，半粗體。
- **卡片標題 (Card Title)**：`24~28 pt`，加粗。
- **內文正文 (Body Text)**：`18~21 pt`，行距約 1.2~1.3 倍。
- **補充說明 / 來源 (Caption / Footnote)**：`14~16 pt`，淡灰色。
- **微標籤 (Badge)**：`18~22 pt`，白字或深色底色。

---

## 五、PowerPoint 數學與公式處理 (Math Text In PowerPoint)

- 保持一般中文說明在原生可編輯文字方塊中。
- 若有複雜公式符號，公式部分獨立為單獨文字方塊或生成為高解析度透明背景 PNG 貼入。
- 嚴禁長篇中文與複雜公式塞在同一個容易破版換行的混合方塊內。
