# SOIL Engines（SOIL 六大教學引擎）

SOIL 教學投影片架構由六個循序漸進的引擎驅動，確保簡報具備「教學結構力」與「認知負載減輕力」。

---

## 引擎 1：概念定位稿 (Concept Positioning)

目標：將龐雜教材濃縮為單一教學核心，明確區分投影片畫面與口語表達。

```markdown
## 概念定位稿

### 一、總概念 (The One Big Idea)
[一句話核心：本節課學生最重要、必須學會的一個核心觀念]

### 二、三個子概念 (Three Sub-Ideas)
1. [子概念 1：先備知識與基石]
2. [子概念 2：核心操作或機制]
3. [子概念 3：應用或延伸推論]

### 三、三個常見迷思與澄清 (Misconceptions & Clarifications)
1. 迷思：[...] -> 正確理解：[...]
2. 迷思：[...] -> 正確理解：[...]
3. 迷思：[...] -> 正確理解：[...]

### 四、帶走一句話 (Takeaway Sentence)
[下課後一個月，學生依然能脫口而出的關鍵口訣或觀念金句]

### 五、最小事實包 (Minimal Fact Pack)
- 必備術語 / 定義：[...]
- 關鍵數字 / 符號：[...]

### 六、投影片 vs 講稿分配表 (Slide-vs-Talk Allocation)
| 內容要點 | 建議呈現位置（投影片畫面 / 備忘口語） | 決策原因（認知減負/避免照唸） |
|---|---|---|
| 核心提問與主圖 | 投影片畫面 | 視覺錨定，引導思考 |
| 詳細案例與情境故事 | 演講者備忘稿 (Oral Talk) | 減輕閱讀負荷，靠聽覺傳達 |
| 易混淆概念對照表 | 投影片畫面 | 雙欄視覺對比，降低工作記憶負擔 |
```

## 引擎 2：脈絡節奏 (Context Positioning)

經典教學三幕劇架構（標準 10 頁配置建議比例：**2 頁 : 6 頁 : 2 頁**）：

1. **引起動機 (Hook - 20%)**：
   - 痛點共鳴、認知衝突、生活情境提問、令人意外的數據或迷思。
   - 讓學生心生：「為什麼會這樣？」、「這跟我有什麼關係？」。
2. **維持注意 (Explain & Practice - 60%)**：
   - 循序解析核心機制（雙欄對照、3 步流程、卡片分類、幾何圖解）。
   - 每 2~3 頁安排一次隨堂小提問或觀察任務，維持注意力曲線。
3. **喚起行動 (Takeaway & Action - 20%)**：
   - 重點總結收束（三點 Takeaways + 帶走一句話）。
   - 具體課後實踐任務或下一次課程預告。

## 引擎 3：頁面架構表 (Page Architecture)

每頁投影片在動工寫程式碼前，必須列出精準規劃：

- **頁碼 (Page No.)**
- **標題 (Title)**：10 字以內
- **頁面角色 (Role)**：封面 / 引起動機 / 迷思澄清 / 概念拆解 / 流程 / 總結 / 行動
- **SOIL 階段 (Stage)**：引起動機 / 維持注意 / 喚起行動
- **單一核心觀念 (One Core Point)**：本頁只傳達的一件事
- **版型配方 (Layout Recipe)**：半欄圖文 / 雙欄卡片 / 三欄流程 / 大數字
- **可編輯文字內容 (Visible Text)**：標題、副標、要點、標籤
- **演講者講稿 (Speaker Notes)**：老師口述細節（供匯入 PPTX 備忘稿）
- **視覺配圖任務 (Visual Prompt)**：AI 底圖/插圖提示詞（標註留白區）
- **幾何/數學圖形 (Geometry)**：是否需要 Python 程式化繪圖

## 引擎 4：認知編修六法 (Cognitive Editing)

依據認知負荷理論（CLT）檢視每頁內容：

1. **降雜訊 (De-noise)**：刪除無教學意涵的裝飾、贅字、重複說明的子句。
2. **區塊化 (Chunking)**：將零散要點分組為 2~4 個邏輯卡片或階段。
3. **增資訊 (Informing)**：在關鍵視覺上加上明確引導箭頭、標籤或色彩標記。
4. **結構化 (Structuring)**：建立絕對清晰的資訊階層（大標 -> 小標 -> 重點正文）。
5. **順脈絡 (Sequencing)**：先備知識在前，衍生應用在後；先提問再解答。
6. **步驟化 (Stepping)**：將複雜步驟拆解為「步驟 1、步驟 2、步驟 3」橫向演進。

## 引擎 5：風格構建 (Style Construction)

定義整套簡報的視覺美學系統：

- **對象與基調**：例如「國小四年級、溫暖活潑、探究好奇」或「高中生、專業俐落、科技感」。
- **主題色票 (Palette)**：
  - 背景色（Background）：淺米白/霧灰（護眼且高對比度）
  - 正文字色（Text）：深灰黑（`#1F2937`，避免死黑）
  - 主色 (Primary Brand)：溫暖深藍或墨綠（`#1E3A8A` 或 `#065F46`）
  - 強調色 (Accent)：暖橘或亮珊瑚（`#EA580C` 或 `#F97316`）
  - 警示/對比色 (Warning/Contrast)：亮紅（`#DC2626`）
- **字型組合**：微軟正黑體 (Microsoft JhengHei) / 蘋方 (PingFang TC)。
- **AI 視覺提示詞風格 Token**：鎖定 3~5 個風格關鍵字，整套投影片重複調用維持畫風一致。

## 引擎 6：腳本生產與建置 (Production)

1. 將規劃轉為 Python `python-pptx` 產生腳本。
2. 預先為視覺圖形或幾何圖形留足空間座標，嚴禁先排滿文字再擠壓圖片。
3. 腳本一鍵自動建置完成 `.pptx` 簡報檔案。
